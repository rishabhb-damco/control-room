# Wellspring — Transcripts Drop Zone

Save meeting transcripts here as `.txt` or `.md` files.

Naming convention: `YYYY-MM-DD_meeting-topic.txt`
Example: `2026-05-14_weekly-sync.txt`

Then say "process transcript" in Claude Code and it will auto-generate:
- Client MOM email
- Internal team briefing
- Action tracker updates
- Brief updates
- Linear-ready paste
