# This repo has been superseded

As of 2026-09-23, this monorepo was split into six standalone, per-project Control Rooms — each with its own git history, its own GitHub repo, and a self-contained `CLAUDE.md`. This folder is kept only as a historical reference; do not do new work here.

| Project | New repo |
|---|---|
| Wellspring | https://github.com/rishabhb-damco/wellspring-control-room |
| eSprinto | https://github.com/rishabhb-damco/esprinto-control-room |
| Kodacars | https://github.com/rishabhb-damco/kodacars-control-room |
| Garuda Aviation | https://github.com/rishabhb-damco/garuda-aviation-control-room |
| CSXAI | https://github.com/rishabhb-damco/csxai-control-room |
| AI Automation | https://github.com/rishabhb-damco/ai-automation-control-room |

Locally, the new folders live alongside this one under `Downloads\`, e.g. `Downloads\Wellspring-Control-Room\`.

`DASHBOARD.md` in this folder (cross-client rollup) and the root `CLAUDE.md`'s "Open [Client]" routing are not replicated anywhere — that convenience went away with the split. Check each project's own folder individually going forward.
