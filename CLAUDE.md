## How to Navigate

To work on a specific client, open their subfolder in Claude Code.

- **"Open Wellspring"** → I'll read all Wellspring files and work in that context
- **"Open eSprinto"** → switches context to eSprinto

- **"Open CSXAI"** → read all CSXAI files and work in that context
- **"Status all clients"** → brief status on all 5 clients from DASHBOARD.md
- **"Update dashboard"** → refresh DASHBOARD.md from all action_tracker.md files
- **"Open AI Automation"** → read AI Automation brief + action tracker, work in that context
- **"AI automation status"** → quick status on the initiative, open actions, next due
